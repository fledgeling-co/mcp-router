# Capabilities

What this skill can reach, in plain language, before you install it anywhere.

| Capability | Scope | Changed at |
|---|---|---|
| Read files | Four session directories, listed in the read me | 1.4.0 |
| Write files | Only the export path you name | 1.3.6 |
| Run programs | `claude`, `grok` — for summarising only | 1.4.0 |
| Network | None | — |

> A capability table is the thing trust decays against. When one of these rows changes, the new
> version is held rather than installed.
