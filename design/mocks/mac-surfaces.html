Conduit — macOS surfaces

Every surface of the Mac app, in the Instrument Panel direction. The single question each surface answers is stated above it, along with what it does in its worst state — because on a tool that installs executable code, the unhappy path is the design.

1 · Menu bar — at rest, and with something waiting

The glyph is silent unless something needs a decision. No call counter, no live badge: an icon that changes constantly is one the eye learns to filter, and then it filters the one change that mattered.

Question: is anything wrong, and what just happened? · Worst state: the daemon is not running, and the popover says so in the sentence that names the reason.

2 · Servers — the breaker panel ◆ signature

Each server is a breaker sitting dormant. The instant an agent calls it, the lever snaps up on its own and its pilot LED goes green; when the idle reaper closes it the lever eases back down over 600ms. This is not decoration — it is a literal rendering of the one mechanism the product exists for, so you watch lazy-spawn happen rather than read that it happened. A server that failed to start trips red and stays down until you deal with it.

Question: what is running right now, and what is it costing me? · Worst state: a tripped breaker, which never silently re-arms.

3 · Skills — one row, every client

A skill is not installed or not installed; it is installed into some clients. The slot strip is the whole answer: one slot per client on this machine, filled or empty, so "where does this actually exist" is read rather than clicked into. The eval mark rides on the row here exactly as it does in Discover and on the phone — a pass/fail that lives only inside a report is a report nobody opens.

Question: what have I got, where is it, and has anyone checked it? · Worst state: a skill whose upstream repo changed hands, which is refused for deletion until read.

4 · Discover — popular is a level, trending is a derivative

Two bands, because editorial and measured are different claims and a single ranked list has to pretend one is the other. Trending carries a window and a signed delta; without both it is just "popular" in a different font. Rows do not carry an install button: one tap from a gameable ranking to executing someone's code is the affordance the adversary wants. You open it, and you install from the detail.

Question: what is worth my attention that I don't already have? · Worst state: a rate-limited index, which says so rather than silently returning a short list.

5 · The update gate — capability diff before content diff

The heart of the product. A new version never applies live: it lands as a shadow copy, the evals re-run against it, and it promotes itself only if the capability diff is empty. Most updates are empty and promote silently with no notification at all. This one is not, so it stopped and is showing you exactly what grew — the checklist first, because a 400-line diff gets click-through-approved and a four-line capability delta does not.

Question: is this version still the thing I agreed to run? · Worst state: it grew capability, which is this one, and nothing happens until you say so.

6 · Evals — watched, not scored

An eval is a transcript you can read, not a number someone else computed. Each case is a prompt, the response, and a verdict; a failure freezes on the exchange that failed rather than collapsing to a badge. The result becomes a property of the skill carried into every other view, which is the only reason anyone sees it.

Question: does this actually do what it says? · Worst state: a case fails, and the failing exchange is the thing on screen.

Cleanup states the window it is judging over, because "never used" across four days of history is not evidence of anything. Before offering to delete anything it re-checks the upstream repo, because a dormant capability is precisely the one nothing else re-examines.

Motion spec

Springs, never durations, and every one interruptible. Breaker lever: up on spawn with response 0.18 / damping 0.62 — it overshoots slightly and settles, which is what makes it read as a snap; down on reap over 600ms with damping 1.0, no overshoot, because a release is not an event. Pilot LED: cross-fades 120ms, never blinks. Shadow copy: a promoted version's dashed border solidifies and its opacity goes 0.6 → 1 over 260ms, the only "reward" animation in the app. Rows: new log rows insert at 0.22 with no fade — they slide, because a fading row is unreadable for the half of the animation you are looking at it. Inbox arrival: the sidebar badge scales 1 → 1.25 → 1 once. Under prefers-reduced-motion the breaker changes state with a 100ms cross-fade and everything else cuts.
