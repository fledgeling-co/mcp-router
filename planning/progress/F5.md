# F5 — skill and server use, by version

Branch `ai/n1`, worktree `.worktrees/N1`, base `08a24ed`. **Ready to verify.** Not merged.

## What the item turned out to be

The brief asked for "the exact version of each tool at the moment it was executed". The word doing
the work is **exact**, and three measurements decided the whole design (`planning/specs/spec-F5.md`
§2, taken read-only on this machine on 2026-08-29):

1. **A skill run is observable and its version is not.** `Skill` appears in a Claude Code transcript
   as an ordinary `tool_use` block carrying `{"skill": "…"}`. The `version` on the same line is
   `2.1.2xx` — the harness's own. Nothing in any transcript names the version of the skill that ran,
   so *"the version at the moment it was executed"* is **not recoverable for a past run by any amount
   of parsing**.
2. **Exactly one boundary of version history exists on disk.** All 127 records in
   `plugins/installed_plugins.json` carry `lastUpdated` beside `version`. A run at or after it
   happened while the installed version was live — a deduction. A run before it happened while
   something else was, and that something is nowhere.
3. **The corpus is 59,476 files and 19.5 GB**, and a 200-file sample took 0.5 s, so a full pass is
   ~150 s. `GET /insights` answers inside a request, so the reader is incremental against a
   watermark rather than a walk per call.

## The contradiction in the design of record

`design/mcp-router-console.html` says both of these, 700 lines apart:

- `:2780` — *"Why there is no 'use, by version'* — the router never sees a skill run … the bars were
  counting something nothing here observes."
- `:3490` — *Skill and server use, by version*, crediting `design-review 2.3.1` with 142 runs, under
  the callout *"a run against 1.4.0 never counts toward 1.4.2's evidence"*.

The second table is the thing the first section says is unobservable, and `InsightsBoard.swift` had
already parked it on the first reading. Both are partly right: the router is not on the path, and
the **harness** writes every skill it ran into its own files.

F5 follows the Insights half, and makes `:3525`'s callout a rule the code enforces instead of a
caption. `VersionAtRun` has three cases and two of them credit nothing:

| case | when |
|---|---|
| `attributed(v, since:)` | the newest boundary at or before the run says `v`, **and no later boundary disagrees** |
| `superseded(movedAt:)` | a later boundary carries a different version, so the swap sits on an unknown side of the run |
| `unestablished(reason:)` | no boundary reaches the run, or its timestamp is not orderable |

`supersededRuns` and `unestablishedRuns` are reported **beside** the table, never inside it, and
`attributed + superseded + unestablished == total` — the identity that makes the rows readable as a
fraction of the traffic rather than as the whole of it. **The consequence is stated rather than
hidden: on this machine most historical runs will read as unattributed and the honest table will
look emptier than the mock does.** That is the measurement, and §1 of `DESIGN.md` §10 now records it
so whoever converts the surface expects it.

## Telemetry — what is recorded, where, and what leaves

Nothing leaves this machine. There is no endpoint, key, queue or batch anywhere in the item.

- **Read:** a line's `timestamp`; inside an assistant `tool_use` block, the tool's `name` and, for
  `Skill`, its `skill` input. Four members, and that is the list.
- **Not read:** prompts, assistant prose, tool arguments (including `Skill`'s own `args`), tool
  results, file contents, `cwd`, `gitBranch`, `sessionId`, `requestId`.
- **Written:** `<router home>/invocations.jsonl`, `versions.jsonl`, `invocation-watermarks.json`.
- **Off until pointed somewhere:** the transcript root defaults to absent, and with it absent the
  routes answer 503 naming that rather than serving an empty window.

The claim rests on `InvocationEvent` having **no member** for any of it — not on the reader being
careful — and `InvocationEvent.wireKeys` plus CASE-0263 are what fail if that stops being true.
`scripts/lint/no-telemetry-egress.sh` refuses every outbound-network symbol under the directory and
is in `make lint`; its selftest plants a `URLSession`, requires the gate to redden **and name the
file**, and requires exit 2 on a subject holding no Swift — because this gate asserts an absence, and
one pointed at a renamed directory exits 0 forever.
