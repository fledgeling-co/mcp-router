# M5 — Discover: the registry

**Depends on:** M4.

Browse and install both kinds of capability from the merged official + Smithery
catalogue, plus followed marketplaces.

- Three bands, because they answer different questions: **recently added** (what carries
  a cold catalogue), **popular** (a level), **trending** (a signed delta over a stated
  window — 24h / 7d / 30d, the window being the user's choice, not a hidden editorial
  one).
- Detail-then-install, never install-from-the-list: it must not be one click from a
  gameable ranking to executing someone's code.
- Every entry states its capabilities in plain language before install — what it reads,
  what it contacts, whether it runs shell.
- Where a count is incomplete, say so in the footer rather than presenting a partial
  ranking as total.

Deep link: `?only=mac&pane=discover`.
