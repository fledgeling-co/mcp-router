Connection states

Every state a typed control-API client can put a surface into — one per case of ControlAPIError, one per phase of the /usage/stream call log. The boards are M2's and M3's; the state layer is F3's, and both inherit this copy rather than writing the same failure twice.

Full-pane states

Two failures replace the whole surface, because in both cases nothing on it can be trusted to be current. Every other failure stays local to the thing that failed.

Data-surface states

The same 56pt row geometry throughout, so a surface never changes shape as it loads, empties or degrades. A skeleton that does not match the row it becomes is a layout shift wearing a loading state's clothes.

The call-log stream

The stream is the only thing on the Activity board that can be stale while still looking populated, so its condition is stated rather than implied. Toggle it to see each phase.

Which state answers which failure

The mapping is the deliverable. A client that folds two of these together takes a surface's ability to render them apart with it.
