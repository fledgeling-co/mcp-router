# M8 — Settings, menu-bar popover, schema quarantine

**Depends on:** M3.

Three smaller surfaces that complete the Mac app.

**Menu-bar popover** — the glanceable instrument. What is running right now, the last
few calls, and one action. It opens answering one question and vanishes. Its icon is a
template symbol whose badge appears only when something wants a decision; an icon that
changes constantly is one the eye filters, and then it filters the one change that
mattered.

**Schema quarantine review** — the security surface. When a server's tool descriptions
change after install, show the before/after diff and require an explicit accept. This is
the defence against a server rewriting its own description to redirect an agent.

**Settings** — the router's port and lifecycle, warm-set RAM budget, auto-update policy,
per-client install targets, and the control token. Grouped inset cards, label-left /
control-right on a shared axis. Disabled controls dim in place with a reason.
