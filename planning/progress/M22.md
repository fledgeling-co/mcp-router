## A note on editing this file, and on partial patches

The Fidelity section above was rewritten wholesale rather than patched, and the reason
generalises.

Three edits to it landed **partially**: each was a find-and-replace whose anchor had been valid
when the edit was composed and no longer matched the file by the time it ran, because an earlier
edit in the same session had moved the text. The first replacement in each batch applied, the
second asserted and stopped — and the commit went out carrying half the change. Stale counts then
read as current through two commits, in a file whose entire job is to say what was measured.

**A partial patch is worse than a failed one.** A failed edit leaves a file that is obviously
untouched. A partial one leaves a plausible file nobody re-reads, with some numbers from this run
and some from two runs ago and nothing marking the seam. It is the same family as a citation that
resolved when it was written and quietly stopped resolving — which is why
`parity-manifest-check.sh` resolves every citation on every run rather than trusting that it was
true once.

What worked: read the file, locate the section by line, replace the whole span, print the result
and look at it. What did not: assume the anchor still says what it said.
