M4 — Skills and marketplaces

The design representation for the Skills board and its marketplace management. Authoritative over design/mocks/prototype.html wherever the two disagree, per DESIGN.md's own precedence rule. Dark and light are both authored here; the page follows the system appearance.

Why "unversioned" rather than a version

A skill placed directly in a client's skills directory has no install record and no version anywhere on disk — SKILL.md frontmatter carries name and description only. Printing 1.0.0 for it would be invented. "unversioned" is set in the body font rather than the instrument monospace, because it is a statement about the skill rather than a reading off it, and DESIGN.md §2 reserves monospace for instrument data.

7 · Error — the router refused

Skills

 
The router sent a response this version doesn't understand
The router may be newer or older than this app (no skills endpoint).

The state that matters most for this item. A router that predates M4 serves no skills endpoint, and this is what the board says when it meets one — a version-skew statement with no action, because there is nothing the user can do from here. It is honest and it is not an apology. The same pane renders every other refusal from the same three strings.

13 · Trust decays per version — the held-version review

The brief's load-bearing rule: a new version is held when it wants more than the one before it. A version whose capability surface is unchanged promotes on its own; a version that adds a capability waits for a human. This sheet is what "waits for a human" looks like.

trawl 2.3.0 wants more than 2.2.0

It was fetched and is being kept aside rather than installed. Nothing has changed for any client until you promote it.

  reads  ~/.claude/projects/**
+ runs   scripts/collect.sh
+ network api.fledgeling.app

Two capabilities are new. scripts/collect.sh is invoked by the skill body, and the network host appears in a fetch directive.

Cancel-equivalent leads, the one prominent action trails, and the destructive reading — promoting something that wants more — is not phrased as the safe default (§3.4). The title states the finding rather than asking a question.

The empty-delta case, which is the common one

design-craft updated to 1.15.0

Its capabilities are unchanged from 1.14.0, so it was promoted without asking. Auto-update is on for diolog-plugins.

Reported, never silent — §9's "reversible actions are made reversible and reported". Auto-update is a visible toggle and its state is stated at the moment it acts, which is the only moment the user is thinking about it.

14 · Provenance — the upstream owner changed

changelog-writer changed hands

When you installed it on 14 Feb 2026 this marketplace was acme-tools/skills. It now resolves to unknown-user/skills. The code you have has not changed, and no update will be taken from it until you decide.

A warning about supply chain, phrased as a fact and a decision rather than an alarm. It states what is still true ("the code you have has not changed") because the failure mode of a security banner is panic, and the row's amber marker is a marker, never the only signal.
