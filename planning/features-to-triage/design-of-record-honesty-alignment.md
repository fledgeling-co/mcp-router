## What and why
Visual design specifications and reference mockups are updated to strictly respect the product's honesty guardrails. Current design mockups display unobserved seven-day trend percentages, model-graded evaluation scoreboards, and obsolete configuration panels that the running application does not observe or support. Aligning the reference designs with actual capabilities ensures that visual differential gates compare against achievable, honest user interfaces rather than speculative mockups.

## Acceptance sketch
- Overview and server boards in reference designs display observed metrics without simulated trend percentages.
- Evaluation mockups are updated to show deterministic system checks rather than unbacked AI scoreboards.
- Settings mockups match the active configuration layout, showing menu bar, warm set, and control settings.
- Refusal states in reference mockups accurately convey unsupported hardware or transport capabilities with honest explanation.
